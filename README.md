# Supply-Chain-Network-Design-
Facility location &amp;  capacity allocation  balancing cost and  responsiveness 
Designed a 3-tier assemble-to-order network (3 supplier clusters, 5 
warehouses, 4 assembly units) for 8 dealers and 1,420 units/month against 
a 60-hour delivery limit. Located 3 warehouses in SEZs (Dindigul, Trichy, 
Madurai) to halve space cost; sized storage using SKU and 6-day 
replenishment calculations.
